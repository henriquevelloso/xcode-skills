# Contributing

Report a concrete skill issue with the affected package version, channel,
Xcode version/build, and a minimal non-private example. SDK-sensitive changes
need evidence from public Apple declarations/documentation and the selected
compiler, not invented API signatures. Do not upload private project files,
credentials, recordings, or raw local snapshots.

Keep guidance neutral and scoped. Preserve consuming project architecture,
compatibility requirements, and authorization boundaries. Do not add hooks,
bundled servers or executable integrations as instruction updates. Preserve
upstream attribution; do not claim Apple-derived material is authored here.

Run the commands in the README. Generated manifests, catalogs, source
inventories and release notes must agree with `release.json`. Package versions
are assigned by the maintainer/updater; do not rewrite historical release tags
or notes. A contribution request does not authorize publication or migration.

Community pull requests run checks without publication credentials. They are
not eligible for the owner-authorized updater's automatic merge path. Maintainer
review is required for contributions; the daily routine does not ingest
arbitrary PR content as an instruction source.
